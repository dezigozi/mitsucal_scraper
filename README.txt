============================================================
  みつかる君 全自動スクレイピングツール
  使い方ガイド
============================================================

■ 概要
  「みつかる君」(https://mitsucal.arai-denki.co.jp/mypages/login)
  から全車種・全商品の価格情報を自動取得し、CSVファイルに保存するツールです。

■ 必要環境
  - Python 3.9 以上
  - Google Chrome または Chromium ブラウザ

============================================================
■ セットアップ手順（初回のみ）
============================================================

  ※ 仮想環境（venv）は既に作成済みです。

1. ターミナルでこのフォルダに移動します:

   cd "/Users/dezigozigmail.com/Dropbox/会社/仕事/マイドキュメント/Ｍ／G/生産性向上(働き方改革)/AI/●仕事/mitsucal_scraper"

2. 仮想環境を有効化して実行（run.sh を使うと自動で有効化されます）:

   ./run.sh              ... 本番実行
   ./run.sh --test       ... 環境チェック

   ※ run.sh を使わない場合:
   source venv/bin/activate
   python mitsucal_scraper.py

  ※ pip/playwright が未インストールの場合:
   source venv/bin/activate
   pip install -r requirements.txt
   python -m playwright install chromium

4. ログイン情報を設定します:

   (a) env_template.txt を .env にコピー（またはリネーム）
       copy env_template.txt .env

   (b) .env ファイルをメモ帳等で開き、
       MITSUCAL_USERNAME、MITSUCAL_PASSWORD、MITSUCAL_COMPANY_CODE を
       実際のログインID・パスワード・会社コードに書き換えます。

   ⚠ 注意: .env ファイルにはパスワードが含まれます。
           共有フォルダに置かないでください。

============================================================
■ 実行方法
============================================================

   python mitsucal_scraper.py

   ※ 実行中はブラウザが自動で開き、操作が行われます。
     ブラウザを手動で閉じないでください。

============================================================
■ 出力ファイル
============================================================

   mitsucal_prices.csv  --- 取得した全データ（UTF-8 BOM付き）

   CSV の列:
     - 取得日時     : データ取得日時
     - メーカー     : 自動車メーカー名（TOYOTA等）
     - 車種名       : 車種名（アクア等）
     - 品番         : 商品品番（TY-248等）
     - 品名         : 商品名（市販マット等）
     - 商品メーカー : 商品の製造元メーカー名
     - 税抜価格     : 税抜価格（数値）
     - 価格テキスト : 価格の原文テキスト
     - カテゴリ     : 商品カテゴリ

   ※ Excel で開く場合はそのままダブルクリックで開けます。

============================================================
■ トラブルシューティング
============================================================

  Q: ログインに失敗する
  A: .env ファイルの ID/パスワードが正しいか確認してください。
     debug_login.png が生成されている場合、
     ログイン画面のスクリーンショットを確認できます。

  Q: データが0件になる
  A: サイトのHTML構造が変更された可能性があります。
     debug_cars_page.png や debug_car_*.png を確認し、
     セレクターの調整が必要な場合があります。

  Q: 途中でエラーが出る
  A: scraper.log にエラー詳細が記録されています。
     ネットワーク接続やサイトの応答速度を確認してください。

============================================================
■ カスタマイズ
============================================================

  mitsucal_scraper.py 内の以下の設定を変更できます:

  - headless=False → headless=True
    （ブラウザ画面を表示せずバックグラウンドで実行）

  - slow_mo=300 → 値を小さく（高速化）/ 大きく（安定化）

  - NAV_TIMEOUT, ELEM_TIMEOUT
    （ページ読み込みや要素待ちのタイムアウト時間）
